# Правила для исполнителя — Примени Подпись

Бот MAX ставит визуальный штамп-факсимиле на заявки ЖД (не криптографическая ЭЦП). Устройство и риски — `README.md`, `docs/REPORT.md`, `docs/MAX-DEPLOYMENT.md`.

1. Секреты (`private/max.env`, токен MAX, секрет webhook), PDF и факсимиле клиента не попадают в Git, логи и отчёты.
2. Тесты только на временных данных и с подменённым MAX; в настоящий MAX ничего не отправлять.
3. На сервер только по слову Сергея. Соседние службы (Примени Аудит, VPN, старый ПРИМЕНИ) не трогать.
4. Готово по `docs/DOD.md`. Решения пишутся в `docs/DECISIONS.md` сразу.
