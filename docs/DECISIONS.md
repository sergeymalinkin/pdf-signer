# Решения — Примени Подпись

Новые сверху.

## CODEX 2026-11-24 — очистка только собственного незавершённого download

MAX transport удаляет файл, эксклюзивно созданный текущей попыткой, если поток
оборвался, превышен лимит или заголовок не PDF. Существующий destination не
удаляется и не перезаписывается. Заголовок собирается из первых пяти байтов
потока без повторного полного чтения файла. Пять новых offline тестов используют
только вымышленные bytes и Mock transport; 3 ошибки воспроизведены до правки.
Отдельная Linux/Windows CI job проверяет только transport без клиентских данных.
Полный signer suite и DoD с private PDF/live MAX не объявляются выполненными.

## 2026-10-15 — основа фабрики из Malinkin OS

Взято: правила (`AGENTS.md`), DoD, проверка синтаксиса в GitHub, закрытие соединений SQLite
(`ClosingConnection`): `with sqlite3.connect()` не закрывает соединение, а бот работает постоянно.
Не взято: полные тесты в GitHub (нужны клиентские PDF и факсимиле, в Git их нет); сторож, лимиты ИИ
(ИИ-вызовов нет). Живой цикл MAX остаётся непроверенным: API отвечает 403 `chat.denied`.
