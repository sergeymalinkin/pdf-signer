# Definition of Done — Примени Подпись

Работа закрыта, только когда выполнено всё:

1. Результат работает: живой сценарий пройден на новом коде (служба `primeni-podpis` перезапущена после замены файлов).
2. Тесты зелёные на машине, где есть `private/` (`python -m pytest -q`). В GitHub идёт только проверка синтаксиса: тестам нужны PDF и факсимиле клиента, а их в Git класть нельзя.
3. Изменение в git и на GitHub; бой совпадает с коммитом.
4. Откат понятен и записан в `docs/HANDOFF.md`.
5. Решения с причиной — в `docs/DECISIONS.md`.
6. Следующему не нужен старый чат.

Выкладка на сервер — только по слову Сергея. Заявки и водителям ничего не отправляется ради проверки.
